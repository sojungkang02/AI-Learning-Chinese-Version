# 漫游英语 · ComicLingo

面向学生的漫画英语学习 Web MVP。界面为中文，学习内容为英文。无需 API Key 即可运行完整 Mock 学习流程。

## 产品设计 → 数据契约 → 实现

1. [PRD、用户故事、页面流与架构](docs/PRD.md)
2. [PostgreSQL Prisma 数据模型](prisma/schema.prisma)、[API 契约](docs/API.md)、[AI JSON Schema](lib/schemas.ts)、[独立 prompt 模板](prompts/script.md)
3. 项目结构：

```text
app/

  components/QuizStages.tsx  四阶段指示器与按阶段渲染的支架组件
  api/[...path]/route.ts     服务端 API、用户隔离、积分与宠物事务
  globals.css               响应式布局、键盘焦点、减少动画支持
lib/
  difficulty.ts             可配置 CEFR 参数与考试映射
  generation.ts             六步生成编排、内容检查、缓存与跨字段校验
  providers.ts              LLMProvider / ImageProvider、Mock、远程模型、一次修复
  schemas.ts                Ajv 输出校验
  quiz.ts                   服务端渐隐状态机、评分、掌握度与复习
  db.ts                     SQLite schema、事务、积分账本、商品
prompts/                    剧本及各阶段提示词
prisma/                     PostgreSQL 迁移设计与种子数据
 tests/                     Vitest 与 Playwright
```

## 启动

需要 Node.js 24+（使用内置 `node:sqlite`，无需数据库服务）。

```bash
npm ci --cache /workspace/.npm-cache
npm run db:seed
npm run dev
```

默认 3000 端口。生产构建：`npm run build && npm start`。当前环境已装依赖，开发服务可用 `npm run dev` 重启。`.data/comiclingo.sqlite` 保留所有访客学习、积分、宠物和排行榜数据；请保留此目录并仅部署单进程本地卷。不得将 SQLite 文件放入公开静态资源目录。

`npm run db:seed` 幂等写入六档难度和十七种商品，无敏感信息。首次打开自动创建独立匿名访客和猫咪、两份食物。没有虚构排行榜账户。

## 配置

复制 `.env.example` 到 `.env.local`，保持默认 Mock 无需填写 Key。

| 变量 | 作用 |
|---|---|
| DATA_DIR | 数据目录，默认 `.data` |
| LLM_PROVIDER | `mock`（默认）或 `remote` |
| LLM_BASE_URL | OpenAI-compatible 服务根路径 |
| LLM_API_KEY | 仅服务端使用，不加 NEXT_PUBLIC 前缀 |
| LLM_MODEL | 远程模型名 |
| IMAGE_PROVIDER | `local`（默认）或 `remote` |
| IMAGE_API_KEY | 服务器端图像 Key，可选共用 LLM_API_KEY；不要提交到 Git |
| IMAGE_BASE_URL / IMAGE_MODEL | 图片服务根路径 / 模型，默认 OpenAI / gpt-image-1 |
| DATABASE_URL | 仅 PostgreSQL Prisma 迁移工具使用，本地运行路径不用此变量 |
| PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH | 可选系统 Chromium 路径 |

默认本地模式根据中文、英文或韩文关键词，从 13 个主题选择剧情、词库和三段故事线，并组合不同英语句子。每次生成默认创建新故事，避免最近六次对白重复；只有显式请求 `reuse:true` 才复用版本化缓存。它是程序组合的主题故事，不是任意语义的 LLM 创作。

`LLM_PROVIDER=remote` 时必须配置 LLM_API_KEY；缺失时明确报错，不会假装 AI 已启用。远程分阶段调用以 Schema 校验，失败修复一次。`IMAGE_PROVIDER=remote` 可启用真实图像生成，使用 IMAGE_API_KEY（或显式共用 LLM_API_KEY），默认模型 gpt-image-1。每幅图带入角色设定、学生设想和具体分镜动作，两次失败后回退到对应主题的本地插画，并在返回值和页面标注。默认本地插画使用不同题材背景、构图、道具和人物姿态；它仍是程序绘制的 SVG，不等于 AI 精细作画。

## 测试

```bash
npm test
# 环境已有 Chromium：
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
# 其他机器可先安装浏览器，然后直接运行：
npx playwright install chromium
npm run test:e2e
npm run build
```

Vitest：生成六格/目标词与题目、危险输入改写、Schema 一次修复、重复奖励/递减/每日上限、事务回滚、L3→L0、错误回退、重放拒绝和复习安排。
Playwright：主流程含全部 20 阶段答题、故意答错、支架 DOM 消失检查、词卡、喂食、实际兑换扣分、周榜与刷新持久化；另测跨用户隔离、奖励篡改、并发重复提交、余额不足、移动端无横向溢出。

## 数据、积分与安全

- 每阶段正确才前进；错误退一级，L3 不再后退。客户端不能提交阶段、分数或奖励金额。
- 答题事务同时更新掌握度、账本、宠物经验与 1/3/7/14 天复习。题目 revision 防重复提交；事件唯一键防重复奖励。
- 每日正向奖励上限 200（UTC 日）；同知识点奖励按 `floor(base/(1+次数))` 递减。阅读奖励每漫画一次；消费不重置当日上限。
- 商店余额检查、扣减、账本与库存增加在同一事务；喂食需持有库存；装备需所有权。
- 内容规则在输入与输出检查，危险设想改写；审核日志只存分类与动作，不存原始敏感输入。
- 服务端不向漫画或测验接口返回标准答案。L0 响应不含漫画、例句或释义。
- 导出与删除入口在“隐私与安全”；数据按匿名 Cookie 隔离，Cookie 为 HttpOnly / SameSite=Lax。生产登录、家长授权与会话强化尚未实现。
- TTS 使用浏览器 speechSynthesis，是否有英语语音取决于设备。

## PostgreSQL 设计

`prisma/schema.prisma` 覆盖全部 17 个要求的模型、关系、唯一约束与索引。当前 SQLite 适配器已测试；PostgreSQL schema 是后续迁移设计，未接入运行时。`prisma/seed-postgres.example.ts.txt` 提供迁移种子示例；迁移时需要安装 `@prisma/client`、生成客户端并实现异步事务适配，不能只设置 DATABASE_URL 即切换。

## MVP 完成范围与下一步

已实现：无 Key 主流程、六格漫画示意、可点击词卡与收藏、阅读/单页模式、TTS、五种题型、严格四阶段、答错回退、掌握度、复习队列、积分防重复与日上限、六种伙伴选择、喂食/兑换/装扮、匿名周榜、本人报告、导出删除、自动化测试。

尚未完成的生产能力：

- 正式注册/登录（Supabase/NextAuth）、密码恢复、跨设备账户；当前是访客模式。
- PostgreSQL 实际运行适配、迁移与服务验证；Redis、对象存储和真实图片 Provider 的实机质量验证。
- 真实 LLM 和图片质量验证：没有配置 API Key，外部请求只通过模拟响应测试。免费本地模式已支持 13 个主题与多种剧情/句子，但不能完全理解任意自定义设想；CEFR 尚无完整分级词库/语法/密度验证。
- 严格的模型内容审核、语义安全改写与人工审核后台；关键词规则不是完整未成年人安全保证。
- 近义干扰项质量评估、真实造句评分校准；Mock 评分仅检查基本结构。
- 好友/班级排行榜、教师/家长授权关联、学习时间测量、连续学习天数展示、收藏管理列表。
- 图片按需加载/后台生成任务；当前图片有限量内存缓存并随漫画保存在 SQLite，请求同步生成，进度为阶段提示动画，不是后端实时事件。
- shadcn/ui 组件体系、微信小程序封装、完整无障碍审计和真实用户三分钟验收。

优先迭代：真实认证与 PostgreSQL → 分级内容库/安全审核 → 图片 Provider 与异步队列 → 教师授权和班级学习。

## Render 공개 데모 배포

무료 Mock 데모 설정을 `render.yaml`에 제공합니다. [한국어 배포 안내](docs/RENDER.md)를 따라 Render에서 Blueprint를 만들거나 기존 Web Service에 명령을 입력하세요. Free 서비스의 SQLite 데이터는 재시작·재배포 시 초기화될 수 있습니다. AI Key는 필요하지 않습니다.

## 주제별 생성 업데이트

이전 버전의 고정 환경 문장과 단일 그림을 제거했습니다. 무료 데모는 요리·우주·농구·바다·마법·동물·음악·학교·추리·직장·여행·일상·환경 등 13개 주제의 이야기와 영어 문장, 6컷 장면을 조합합니다. 구체적인 입력 키워드를 장르보다 우선하고, 명시한 영어 목표 단어를 우선 포함합니다. 새로운 생성은 최근 이야기와 겹치지 않게 하며, 기존 만화는 학습 기록에서 계속 열 수 있습니다.

**임의의 사용자 구상을 이해하는 실제 AI 이야기와 정교한 AI 그림**을 사용하려면 Render 서비스의 **Environment**에서 다음을 설정하고 저장·재배포하세요. Key는 채팅이나 저장소에 적지 말고 Render에서만 입력하세요. 외부 AI 사용에는 해당 서비스의 비용과 이용 조건이 적용됩니다.

```text
LLM_PROVIDER=remote
LLM_API_KEY=(Render에 직접 입력)
LLM_MODEL=gpt-4o-mini
IMAGE_PROVIDER=remote
IMAGE_API_KEY=(Render에 직접 입력)
IMAGE_MODEL=gpt-image-1
```

`render.yaml`의 기본값은 계속 무료 로컬 모드입니다. 이 저장소에 Key가 추가되지 않으며, API가 자동으로 활성화되지 않습니다. 실제 외부 모델의 품질·속도·요금은 아직 검증하지 않았습니다.

## 반려동물 꾸미기와 만화 주인공

Aligna 참고 화면의 라벤더 카드·봉제인형 감성을 바탕으로 별도 제작한 6종 캐릭터를 사용합니다. 고양이 2종, 강아지, 카피바라, 양, 토끼 중 선택할 수 있고, 포인트로 모자·옷·안경·목도리·리본 등을 구매해 입히거나 벗길 수 있습니다. 미구매 아이템의 '试穿'은 미리보기이며 결제·저장되지 않습니다. 의류 중복 구매를 막고 같은 부위는 하나씩, 다른 부위는 함께 착용합니다.

만화 생성 화면에서 현재 반려동물과 의상이 주인공으로 표시됩니다. 가상 인물을 최대 두 명 추가해 이름·역할·외모를 정할 수 있습니다. 서버는 사용자 저장값에서 반려동물과 실제 소유·착용 의상을 읽고, 생성 결과에 출연진 스냅샷을 보관합니다. 로컬 만화는 주제 배경 위에 동일한 캐릭터와 의상을 합성하고 추가 인물은 기본 사람 삽화와 의상 색으로 표현합니다. 임의의 상세 외모나 포즈를 자유롭게 그리는 기능은 실제 AI 작화 설정이 필요합니다. 외부 AI 기능은 현재 키가 없어 실서비스 호출을 검증하지 않았습니다.

`public/pets/companions.png`는 이 앱을 위해 생성한 캐릭터 스프라이트입니다. 꾸미기·상점·만화·퀴즈가 같은 `PetAvatar`/`ComicArtwork`를 사용합니다. 기존 반려동물과 구매 내역은 유지되며, SQLite 스키마를 파괴적으로 변경하지 않습니다. Render 무료 플랜의 재시작에 따른 데이터 초기화 제한은 동일합니다.

## 표정·돌봄·장면별 행동

참고 사진처럼 어깨·앞다리·몸통을 자연스럽게 감싸는 동물별 전용 코디 6세트를 추가했습니다(총 상품 17종). 코디는 옷을 몸 앞에 붙이는 방식이 아니라 **이미 옷을 입은 완성형 캐릭터** 이미지입니다. 세트마다 기본·기쁨·놀람·결의·졸림의 5개 얼굴이 있어 착용을 유지한 채 반응합니다. 전용 세트는 해당 동물만 구매·착용할 수 있고 모자/몸통/목 슬롯을 함께 사용합니다. 세트의 모자와 옷은 세트 단위로 입고 벗습니다. 기존 단품 구매 기록과 안경·장난감은 계속 지원합니다.

반려동물 화면의 **摸摸头 / 一起玩 / 洗香香**으로 쓰다듬기·놀아주기·무료 목욕을 할 수 있습니다. 기쁨 반응은 약 12초 표시되고, 친밀도 25 이상에서는 평소에도 기쁜 얼굴이 됩니다. 교류는 친밀도만 올리며 반복 포인트나 경험치를 지급하지 않습니다. 쓰다듬기/놀이는 서버 기준 0.9초 간격을 두고, 이미 깨끗한 상태에서 목욕을 반복해 친밀도를 얻을 수는 없습니다.

미접속 1일은 유예하고 이후 완전히 지난 날마다 청결도 14를 낮추되 최저 20으로 제한합니다. 상태 조회 시 한 번 반영하고 마지막 접속 시각을 갱신하므로 새로고침으로 먼지가 중복 누적되지 않습니다. 더러우면 흙자국과 잎사귀, 졸린 표정으로 표현하고 무료 목욕으로 즉시 100으로 회복합니다. 포인트·보유품·레벨을 차감하지 않으며 질병·죽음·파괴 상태는 없습니다.

각 만화 컷에 `petState.emotion` / `petState.action`을 저장합니다. 호기심→놀람/걱정→결의→기쁨 등 장면에 맞는 얼굴, 흔들림·점프·달리기·축하 움직임을 사용하고, 외부 AI 작화에도 같은 지시를 보냅니다. 로컬 표현은 준비된 얼굴 이미지와 CSS 애니메이션을 합성하는 방식이며 임의의 자세를 AI로 새로 그리는 것은 아닙니다. `prefers-reduced-motion`에서는 움직임을 끕니다.

SQLite는 기존 `pets`를 변경하지 않고 `pet_care` 테이블을 추가합니다. 서버 시간으로 상태를 계산하고 방문/상호작용을 트랜잭션 처리합니다. 데이터 내보내기에 돌봄 상태가 포함되고 전체 삭제 시 함께 삭제합니다. PostgreSQL Prisma 모델에도 PetCare를 추가했지만 PostgreSQL 실행 경로는 기존과 같이 미연결 상태입니다. 서버 로컬 파일을 잃으면 돌봄 기록도 사라지므로 Render 무료 플랜의 저장 제한은 그대로 적용됩니다.

## 기존 단품도 자연스러운 착용 모습으로 갱신

기존 `hat`, `beret`, `crown`, `sweater`, `overalls`의 평면 SVG 장식 렌더링을 제거했습니다. 아이템 ID·가격·인벤토리·포인트 내역은 그대로이며 재구매 없이 새 외관이 적용됩니다. 모자 3종/몸통 의류 2종의 단독 착용과 모든 동시 착용을 합친 11가지 구성에 대해, 6종 동물과 5개 얼굴 상태가 포함된 완성형 착용 이미지를 제공합니다. 어깨·소매·앞다리·몸통이 자연스럽게 연결된 모습입니다. 안경·목도리·리본·장난감 같은 다른 액세서리는 기존 레이어 방식으로 계속 지원하며 이번 입체 이미지 교체 대상은 위 모자·몸통 의류 5종입니다.

`lib/pet-looks.ts`가 현재 착용 슬롯과 동물·표정을 실제 이미지로 연결합니다. `PetAvatar`를 공유하므로 상점 썸네일, 미리보기, 보유 의상, 홈 캐릭터, 로컬 만화와 퀴즈에 모두 적용됩니다. `public/pets/looks/*.webp`는 생성한 이미지의 WebP 인코딩 결과이며 서버의 AI 호출을 추가하지 않습니다. 새 세트를 구매하도록 우회하지 않고 기존 단품 자체의 표시를 갱신합니다.

브라우저 테스트는 기존 구매/착용 내역을 가진 방문자가 추가 비용 없이 새 이미지를 보는지, 기존 슬롯 교체가 유지되는지, 6종 모두에 같은 조합이 적용되는지, 이미지 파일 전체가 실제로 디코딩되는지 확인합니다. 공개 배포 상태는 별도로 `/api/health`의 `release`와 `commit`으로 확인할 수 있습니다.
