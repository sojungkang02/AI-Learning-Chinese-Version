# 漫游英语 MVP
学生选择可配置的考试/CEFR 难度、题材、画风和设想，生成六格漫画，学习五个知识点，逐点通过四阶段测验，获得积分并养宠物。

## 用户故事与页面流
学生：档案 → 创作 → 进度 → 阅读/词卡 → 测验 → 结果 → 宠物/商店/周榜。
复习者：到期复习/错题本 → 四阶段测验。教师与家长：只查看汇总报告。

## 架构与边界
Next.js App Router、TypeScript、Tailwind；Node SQLite 持久化，BEGIN IMMEDIATE 事务校验积分、兑换与答题。每个匿名访客有 HttpOnly 会话，数据按用户隔离。此身份是演示访客身份，不是生产登录系统。
PostgreSQL Prisma schema 用作生产迁移设计，当前运行路径不依赖 PostgreSQL。LLMProvider 支持 mock 与 OpenAI-compatible 服务；ImageProvider 默认 SVG 插画，可替换外部服务。Ajv 校验各生成阶段，失败只修复一次。图像有缓存、重试与占位。

## 验收与约束
默认未成年人模式；不含支付或随机奖励。每日积分上限 200，重复事件不重发、同知识点奖励递减。服务端保存题目和支架阶段，不信任客户端传入分数。每个词依次 L3/L2/L1/L0；错答退一级，L3 保持。复习为首次掌握后 1/3/7/14 天。
首次主流程可用默认五词快速体验；三分钟完成是产品目标，尚未进行真实用户计时验证。
